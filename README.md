# 살까 말까 보관함

사고 싶은 마음, 잠깐 맡겨두세요. 상품을 저장하고 24시간·48시간·7일의 숙려 기간이 지난 뒤 구매 여부를 기록하는 앱인토스용 웹앱입니다.

## 첫 버전 기능

- 상품 이름·가격·카테고리·구매 이유와 사용 계획 기록
- 선택한 숙려 시간이 지나면 구매 또는 구매 포기 기록
- 하루 더 고민하기, 결정 되돌리기, 삭제 전 확인
- 구매한 물건의 만족도 1~5점 기록
- 보관함 검색과 결정 대기 필터, 구매·포기 기록 필터
- 한국 시간의 **결정한 날짜**를 기준으로 월간 금액·건수·카테고리·만족도 집계
- 모바일과 데스크톱에 맞춘 화면, 키보드 접근 가능한 기본 다이얼로그
- 토스 사용자별 기기 저장소와 일반 브라우저의 로컬 저장소 지원

실제 결제·송금·계좌 연동은 없습니다. ‘안 사기로 한 금액’은 직접 입력한 상품 가격의 합계이며, 실제 저축액이 아닙니다. 첫 실행은 빈 보관함으로 시작하고 예시 데이터를 통계에 넣지 않습니다.

## 실행하기

Node.js 22.12 이상과 npm을 사용합니다.

```sh
npm ci
npm run dev
```

일반 브라우저에서 `http://localhost:3000`을 엽니다. 서버·API 키·환경 변수 없이 실행할 수 있습니다.

```sh
npm run typecheck  # TypeScript 검사
npm test          # 숙려·통계·저장·화면 흐름 테스트
npm run build:web # dist/ 정적 웹 빌드
npm run build     # 웹 빌드 후 salka-malka.ait 생성
```

## 앱인토스 업로드 준비

SDK 3.10.0과 TDS Mobile 2.5.1을 사용합니다. SSR 없이 Vite로 정적 파일을 빌드합니다. 현재 설정의 앱 식별자는 `salka-malka`입니다. GitHub 저장소 이름과 앱인토스 식별자는 서로 달라도 됩니다.

1. 앱인토스 콘솔에서 미니앱을 등록합니다. 표시 이름은 **살까 말까 보관함**, 카테고리는 실제 서비스 목적에 맞게 선택합니다.
2. 콘솔의 실제 `appName`을 `apps-in-toss.config.ts`의 `appName`과 일치시킵니다. 앱 식별자를 바꾸면 생성되는 `.ait` 이름도 바뀝니다.
3. 콘솔에 로고·앱 설명·고객센터·개인정보 처리 안내 등 실제 운영 정보를 등록합니다. `public/icon.svg`는 웹용 벡터 로고 원본입니다. 콘솔의 이미지 규격에 맞게 별도로 준비하세요.
4. `npm run build`로 생성한 `<appName>.ait`를 콘솔에 업로드합니다. 이 파일은 빌드 결과물이므로 Git에서 제외합니다.
5. 콘솔의 테스트용 스킴으로 실제 토스 앱에서 저장·재실행·뒤로가기·키보드·스크롤을 확인합니다. 최소 지원 앱 버전에서 익명 식별키와 저장소 API도 확인해야 합니다.
6. [비게임 출시 가이드](https://developers-apps-in-toss.toss.im/checklist/app-nongame.md)에 따라 확인한 뒤 검수를 요청합니다.

**GitHub 푸시와 `.ait` 빌드가 앱인토스 출시 또는 검수 승인을 의미하지 않습니다.** 이 저장소에는 서버·광고·결제·푸시알림을 연결하지 않았습니다. 사용자가 앱을 다시 열어 숙려가 끝난 물건을 확인하는 방식입니다.

## 데이터 저장 방식

- **토스 WebView:** `User.getAnonymousKey()`의 식별키를 저장 키에 포함하고 `Storage.getItem/setItem`을 사용합니다. 익명 키를 서버로 보내지 않습니다.
- **일반 브라우저:** 해당 브라우저 `localStorage`의 `salka-malka:v1` 키에 저장합니다.
- 두 환경의 기록은 서로 자동 이전하지 않으며 다른 기기로 동기화되지 않습니다.
- 저장 성공 후에만 화면 상태를 갱신합니다. 저장 실패 시 입력창과 기존 기록을 유지합니다.
- 데이터가 손상되었거나 토스 식별이 실패하면 저장을 막고 기존 데이터를 덮어쓰지 않습니다. 네이티브 저장 오류를 브라우저 저장소로 우회하지 않습니다.
- 앱·브라우저 데이터 삭제나 기기 교체 시 기록이 사라질 수 있습니다. 각 상세 화면에서 개별 기록을 삭제할 수 있습니다.

브라우저 데이터 형식은 버전이 있는 JSON입니다. 익명 키·이름·가격·메모를 로그로 출력하지 않습니다. 이미지 업로드·외부 상품 링크·상품 정보 수집 기능은 없습니다.

## 구조

```text
src/
  App.tsx               화면과 사용자 동작
  model.ts              숙려·결정·한국 시간 월간 통계 규칙
  storage.ts            토스 / 브라우저 저장소 어댑터
  useWishes.ts          로드·저장 및 실패 처리
  components/           폼, 상세, 카드, 월간 돌아보기
tests/                  핵심 규칙과 실제 컴포넌트 동작 테스트
apps-in-toss.config.ts  앱인토스 SDK 3.x 설정
```

## 검증 범위

자동 검증은 TypeScript, Vitest의 DOM 기반 사용자 흐름, 정적 웹 빌드, `.ait` 번들 생성을 포함합니다. 실제 브라우저의 배치·터치 및 토스 앱 안의 브릿지·기기 저장소는 별도 확인이 필요합니다. 토스 API를 호출하는 코드는 브라우저 저장소 테스트만으로 검증되었다고 간주하지 않습니다.
