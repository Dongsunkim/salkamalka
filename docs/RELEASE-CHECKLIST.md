# 앱인토스 실제 기기 확인

이 문서는 자동 테스트로 확인할 수 없는 운영 준비 항목입니다.

- [ ] 콘솔의 실제 appName과 설정 파일의 값이 같음
- [ ] 앱 로고·설명·고객센터·개인정보 처리 안내 등 실제 운영 정보 등록
- [ ] 최신 `.ait`를 콘솔에 업로드하고 토스 테스트용 스킴으로 실행
- [ ] 안드로이드와 iOS에서 상품 등록·한글 입력·가격 입력·스크롤 확인
- [ ] 앱 종료 후 다시 실행해 기록 유지 확인
- [ ] 토스 사용자 변경 시 다른 사용자의 기록이 표시되지 않는지 확인
- [ ] 숙려 기간 전에는 구매 결정이 비활성화되고 만료 후 활성화됨
- [ ] 구매·포기·결정 되돌리기·하루 더 고민하기·만족도·삭제 확인
- [ ] 월간 통계가 결정한 날짜의 한국 시간 기준으로 계산됨
- [ ] 시스템 뒤로가기에서 열린 다이얼로그 닫기 → 보관함 → 앱 종료 순서 확인
- [ ] 홈·닫기·더보기 등 토스 공통 네비게이션 정상 동작
- [ ] 키보드 사용 중 하단 버튼 및 입력 내용 접근 가능
- [ ] 저장소 오류 시 기존 기록과 입력 내용이 유지됨
- [ ] 네트워크 권한·기기 권한을 불필요하게 요구하지 않음
- [ ] 비게임 출시 가이드의 최신 항목 확인 후 검수 요청
